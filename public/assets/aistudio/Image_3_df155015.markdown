## Brand & Style

The design system establishes a high-trust, institutional digital banking language rooted in stability, precision, and executive modernity. It bridges heritage retail banking with contemporary wealth-management fluidity, catering to retail savers, corporate treasurers, and high-net-worth investors alike.

The interface evokes uncompromising security, speed, and fiscal clarity. Visual density is balanced: high information throughput without cognitive fatigue. The aesthetic marries **Corporate / Modern** precision with **Glassmorphism-accented structural layering**—featuring razor-sharp typographic discipline, subtle ice-blue environmental tinting, and structured data hierarchy to render complex monetary movements immediate and actionable.

## Colors

The palette leverages institutional navy `#012169` as an uncompromising foundation of solvency and governance, paired with signature crimson `#E31837` (with historical anchor `#D4001A`) strictly reserved for primary conversion triggers, urgent transactional flags, and strategic brand anchors.

### Role Assignments
- **Primary Navy (`#012169`)**: Core app navigation bars, high-prominence headers, key KPI counters, and primary container fills.
- **Secondary Crimson (`#E31837`)**: Transaction authorization buttons, active alerts, primary marketing CTAs, and selected active indicator tabs. Never use for mundane text or expansive card backgrounds.
- **Tertiary (`#1A73E8`)**: Informational status indicators, linked sub-routes, and secondary data visualizations.
- **Ice Blue Surfaces (`#F2F6FA` / `#E8EFF7`)**: The default canvas backdrop and nested dashboard container surfaces, departing from stark sterile whites to minimize eye fatigue during extended session times.
- **Slate Borders (`#D5DFEB`)**: Structural hair-lines establishing clean ledger columns, card frames, and security boundaries.

## Typography

Typography prioritizes high-speed scan speed and numerical precision. **Manrope** provides authoritative, geometric structure to balance sheets, portfolio headlines, and page sections. **Inter** handles high-density fiscal tables, fine transaction ledgers, form controls, and labels.

### Numerical Typography Rules
- All currency representations, account balances, IBAN formats, and routing figures must enforce tabular figures (`font-variant-numeric: tabular-nums; lining-nums;`) to guarantee strict vertical alignment across rows and summary stacks.
- Display and `headline-lg` styles utilize negative letter-spacing to maintain typographic tension and executive presence.

## Layout & Spacing

The layout is built around an analytical 12-column responsive fluid grid anchored by maximum horizontal boundaries (1360px desktop container cap).

### Breakpoints & Adaptations
- **Desktop (1024px+)**: 12 columns, 24px (`1.5rem`) gutters, 48px (`3rem`) side margins. Accommodates multi-tier account summaries, sidebar navigation, and side-by-side transaction ledgers.
- **Tablet (768px – 1023px)**: 8 columns, 20px gutters, 32px side margins. Data tables collapse secondary audit columns; balance widgets reflow into 2x2 matrices.
- **Mobile (0px – 767px)**: 4 columns, 16px (`1rem`) gutters, 16px (`1rem`) margins. Navigation converts to an anchored bottom security bar; account action groups stack vertically.

### Rhythmic Rules
All padding, card offsets, and row separation must adhere to strict 8pt stepping multiples (derived via `space-*` tokens). Compact interactive components (input cells, data table rows) leverage dense 4px subdivisions (`space-xs`).

## Elevation & Depth

Visual hierarchy uses a refined hybrid of **tonal layered surfaces** and **whisper-light ambient shadows** tinted with Navy (`#012169`), completely bypassing murky black shadows to preserve crisp luminosity.

### Elevation Levels
- **Layer 0 (Canvas Background)**: `#F2F6FA` (Ice Blue Surface). Flat, no shadow.
- **Layer 1 (Card & Module Surfaces)**: Pure `#FFFFFF` resting upon `#F2F6FA`. Outlined with a 1px boundary of `#D5DFEB`. Shadow: `0px 2px 4px rgba(1, 33, 105, 0.03), 0px 8px 16px rgba(1, 33, 105, 0.04)`.
- **Layer 2 (Interactive Floating Elements & Dropdowns)**: Pure `#FFFFFF`. Shadow: `0px 4px 12px rgba(1, 33, 105, 0.06), 0px 16px 32px rgba(1, 33, 105, 0.08)`.
- **Layer 3 (Modals & Authorization Sheets)**: `#FFFFFF` overlaid atop a 40% Navy backdrop blur (`rgba(1, 33, 105, 0.40)` with `backdrop-filter: blur(8px)`). Shadow: `0px 24px 48px -12px rgba(1, 33, 105, 0.18)`.

## Shapes

The design system adheres to a disciplined, restrained **Soft (`1`)** roundedness profile. This communicates institutional endurance, legal precision, and technical dependability over playful informality.

### Shape Metrics
- **Inputs, Buttons, Badges, Table Rows**: `0.25rem` (4px). Clean, crisp corners that feel precision-machined.
- **Standard Cards, Dashboard Modules, Sheets**: `0.5rem` (8px, `rounded-lg`). Gentle enough to prevent visual harshness without degrading analytical rigidity.
- **Security Badges & Status Pills**: Strict full-radius pills (`rounded-full`) exclusively used to denote transient contextual states (e.g., "Cleared", "Pending", "Encrypted").

## Components

### Buttons
- **Primary CTA**: `#E31837` fill, text `#FFFFFF`, 4px border radius, font `label-lg`. On hover: `#D4001A`. Active: subtle inset press `scale(0.99)`.
- **Secondary Institutional**: `#012169` fill, text `#FFFFFF`. Used for account actions, transfers, and report exports.
- **Secondary Ghost / Outline**: 1px border `#D5DFEB`, background transparent, text `#012169`. On hover: background `#F2F6FA`.

### Cards & Ledger Containers
- **Financial Account Card**: Background `#FFFFFF`, border `1px solid #D5DFEB`, radius `8px`. Top-accented with an optional 3px hairline band (Navy for checking/savings, Crimson for credit, Emerald for investments).
- **Metric Cards**: Display large-format monetary amounts (`headline-lg` in Manrope) with a muted label atop and an inline directional trend badge (`success-emerald` or crimson text).

### Form Controls & Inputs
- **Text & Number Inputs**: Background `#FFFFFF`, 1px solid border `#D5DFEB`, padding `10px 14px`, text `body-md`. Focus state introduces a crisp `2px` focus ring in `#012169` with a `0 0 0 3px rgba(1, 33, 105, 0.12)` glow.
- **Account Number / Routing Inputs**: Enforce monospaced tracking and automatic masking toggle.

### Badges & Security Indicators
- **Security Badge**: Pill shape, 1px border in `#D5DFEB`, background `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(4px)`. Features a 6px status dot (Emerald `#0D8249` for encrypted/verified session, Gold `#B38200` for MFA required) followed by `label-sm` tracking.
- **Transaction Status Pill**: High-contrast, micro-padding (`2px 8px`), uppercase `label-sm` with semantic background tints (`#E6F4EA` for settled, `#FFF3D6` for pending).

### Data Tables & Transaction Ledgers
- Table headers set in `label-md`, uppercase, muted navy tone (`#475569`), separated by a clean 1px bottom border.
- Alternate rows carry subtle hover transitions (`background-color: #F8FAFC`). Trailing values (debit/credit figures) align flush right with explicit `+` or `−` prefixes.
